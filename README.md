**⚠️Note: Important - Running the Projects**

Part 1 and Part 2 are separate Java projects. Both parts contain some classes with the same names, so their `src` folders should not be marked as Sources Root at the same time in the same IntelliJ project.

**Currently:** Part 1 `src` is set as the **Sources Root**, so Part 1 can be run directly.

**To run Part 2:**
1. Right-click **Part 1 → `src`** → **Mark Directory as → Cancel Sources Root**.
2. Right-click **Part 2 → `src`** → **Mark Directory as → Sources Root**.
3. Run `CityRideLite.java` from Part 2.

To switch back to Part 1, reverse the process by making Part 1 `src` the Sources Root and unmarking Part 2 `src`.
